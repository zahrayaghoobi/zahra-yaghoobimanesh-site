# وب‌سایت شخصی زهرا یعقوبی منش (Next.js)

## اجرا به‌صورت محلی
1. Node.js نسخه 18.18 یا بالاتر را نصب کنید.
2. در همین پوشه: `npm install`
3. کلید OpenRouter را با نام `OPENROUTER_API_KEY` در فایل `.env` ریشه پروژه قرار دهید.
4. `npm run dev` و سپس باز کردن http://localhost:3000

گفتگوی دوقلوی دیجیتال فقط در نسخه Next.js فعال است و از مدل `nvidia/nemotron-3-ultra-550b-a55b:free` استفاده می‌کند. کلید API فقط در سرور خوانده می‌شود و نباید در کد مرورگر قرار گیرد. نسخه استاتیک ساخته‌شده با `build-static.mjs` به API گفتگو دسترسی ندارد.

نسخه نهایی: `npm run build && npm start`

## ویرایش محتوا
- متن‌ها، سوابق و نمونه‌کارها: `data/content.js`
- تصاویر و رزومه: پوشه `public/`
- ظاهر: `app/globals.css`

### تغییرات محتوایی اخیر
- معرفی حرفه‌ای بر طراحی مکانیک، توسعه محصول، مهندسی ایجنت و ساخت ابزارهای هوشمند تمرکز دارد.
- بخش «تمرکز فعلی من» به معرفی اضافه شده و مهارت‌های مرتبط با Agent و برنامه‌نویسی با هوش مصنوعی در فهرست تخصص‌ها قرار دارند.
- تحصیلات شامل کارشناسی مهندسی رباتیک و کارشناسی ناپیوسته مدیریت بازرگانی در موسسه آموزش عالی کاویان (۱۴۰۲–۱۴۰۴) است.
- دکمه ورود به چت با عنوان «پاسخگوی سوالات شما» نمایش داده می‌شود. محتوای مرجع چت نیز از اطلاعات همین فایل خوانده می‌شود.
- اطلاعات تماس شامل شناسه تلگرام و پیوند LinkedIn است؛ انتخاب شماره گزینه تماس یا پیامک را نشان می‌دهد و کلیک روی ایمیل آن را کپی می‌کند.

## نسخه استاتیک (بدون نصب)
فایل `index.html` را مستقیم در مرورگر باز کنید. بعد از تغییر `data/content.js` یا `app/globals.css`، دستور `node build-static.mjs` آن را دوباره می‌سازد.
